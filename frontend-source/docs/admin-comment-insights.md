# 后台评论识别说明

## 现状
- 当前“评论识别/评论审查”是前端本地规则识别，不依赖后端模型服务。
- 在后台管理弹窗中展示评论统计、风险词命中与风险评论列表。

## 数据来源
- 来源于现有 Pinia `workspace` 状态中的项目、任务、评论数据：
  - 项目：`allProjects`
  - 任务：`project.tasks`
  - 评论：`task.comments`

## 风险词列表
- 风险词在 `src/stores/workspace/getters.js` 内部常量维护：
  - 错
  - 返工
  - 没拿到
  - 风险
  - 加班
  - 版权
  - 延期
  - 不确定
  - 等客户

## 当前统计项
- 评论总数
- 风险评论数量
- 评论最多的用户
- 评论最多的任务

## 后续扩展建议
- 可接入后端审核接口，统一风险词配置、增加命中权重和审计留痕。
- 可接入 AI 审核模型，支持语义风险识别、误报过滤和分级告警。
