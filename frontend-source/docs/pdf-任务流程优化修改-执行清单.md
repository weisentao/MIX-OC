# 任务流程优化修改执行清单

来源：`任务流程优化修改(1).pdf`

## 项目树

- 项目汇总总数显示一级分类数，不显示所有项目总数。
- 一级分类右侧数字显示该分类下项目数量；没有项目时不显示数字，也不显示展开箭头。
- 当前数据需要修正为：王者荣耀爆料 2 项、英雄联盟/金铲铲 0 项、穿越火线/手游/HD 1 项。
- 项目右侧“协同成员”入口改为“优化”，点击进入该项目的优化清单。
- 项目周期展示为 `项目周期 YYYY/MM/DD-YYYY/MM/DD`，数据来自该项目排期任务的起止时间，点击可跳到排期。
- 原“降 / 归入下级”改为“置顶”，把当前分类或模板目录移动到第一位。

## 模板树

- 点击模板名称只打开模板待完成任务列表，不复制到项目汇总。
- 新建模板后立即切到该模板的流程界面，待完成列表为空，并保持“全部”任务筛选。
- 点击“用”才复制模板到项目汇总根目录，项目名称不追加“项目”二字。
- 模板“共”用于共享给其他用户；已共享时显示淡蓝色。
- “共享给我的模版”是固定功能栏，不允许创建、删除、拖拽归放。
- 删除模板时同步删除共享副本；重命名模板时同步更新共享记录。

## 流程界面

- 流程界面整体按全屏区域缩小 10%，即视觉缩放为 90%，但仍撑满可视区域。
- 收起箭头显示为大于号方向，展开箭头向下且居中。
- 完成归档动画要克制、稳定，避免散乱飞动。
