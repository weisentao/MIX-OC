# MIX-OC v1.0.2 发布说明

发布日期：2026-05-19

`v1.0.2` 是一次面向协同通讯录、项目成员权限、模板共享、部门统一口径和人力资源视图的迭代。这个版本让前端 UI 的批量选择、权限分组、成员摘要和模板共享体验更完整，同时让后端接口在 `userId`、部门 canonical key、共享权限和旧字段兼容上更稳定。

## 更新摘要

- 协同成员弹窗支持通讯录批量选择、部门树筛选、搜索和已选成员预览。
- 项目成员管理按“管理 / 编辑 / 只读”分组，支持权限调整和成员移除。
- 模板共享支持“可编辑 / 只读”权限区，后端返回规范化 `recipients` 和 `permissions`。
- 部门 taxonomy 固化为项目管理、AIGC、美术设计、三维动态、动效设计、视效包装。
- 历史“后期合成”统一展示为“视效包装”，三维动画等旧称归一到“三维动态”。
- 项目成员写入优先使用 `userId`，继续兼容姓名数组和 `memberRoles`。
- 人力资源、通讯录、工作区部门和项目成员接口补齐结构化部门字段。
- README、Release notes 和 package 说明重新整理，并补充多组折叠截图。

## 新增功能

### 协同通讯录批量选择

协同成员弹窗现在可以从通讯录一次选择多个成员加入项目。左侧部门树按照统一部门顺序展示，右侧列表支持搜索、已加入状态提示和已选成员预览，项目经理不再需要逐个补成员。

### 项目成员权限分组

项目成员管理从简单成员列表升级为“管理 / 编辑 / 只读”三组。前端展示更清晰，后端契约也开始保留结构化成员对象，为后续多端同步和权限校验做准备。

### 模板共享权限区

模板共享弹窗支持把共享对象分到“可编辑”和“只读”区域。后端共享接口兼容 `entries`、`recipients`、`sharedWith`、`users`、`userIds` 和单用户对象，并统一返回 recipients、entries、permissions 和 legacy `sharedWith`。

### 统一部门 taxonomy

后端新增 `department-taxonomy` 工具，统一部门 canonical key、展示名、子部门、别名和排序。当前固定顺序为：

```text
project-management
aigc
art-design
three-dynamic
motion-design
visual-packaging
```

历史“后期合成一部 / 二部 / 三部”会映射到“视效包装一部 / 二部 / 三部”，三维动画等旧名称会映射到“三维动态”。

## 优化体验

项目头部最多展示 3 个成员头像，并显示总人数或额外人数，项目列表和详情页的信息密度更可控。通讯录详情补齐姓名、部门、岗位、邮箱、手机、MBTI、头像和在线状态，让协作入口不只是“选人”，也能快速确认人员信息。

人力资源视图使用统一部门别名进行筛选，超级管理、部门经理和个人视角看到的部门结果更一致。人力指派、负载风险和 AI 建议相关后端提示改为中文，用户在超负荷确认、候选人推荐和服务异常时能直接理解下一步动作。

README 与发布资料重新整理，顶部增加产品简介和版本摘要，截图按工作台、排期、协同、人力、更多验收图折叠展示。用户进入仓库后可以先看简短介绍，再展开自己关心的功能区域。

## 修复问题

- 修复模板共享接口只接受单一共享结构的问题，批量 recipients、权限 map 和 legacy `sharedWith` 都可以被识别。
- 修复 `write` / `edit` / `manage` / `owner` 等共享权限别名在前端展示和后端保存不一致的问题。
- 修复项目成员写入容易退化为姓名匹配的问题，后端现在优先使用 `userId`，姓名只作为展示兼容字段。
- 修复部门列表、人力资源筛选和工作区部门接口对历史部门名覆盖不足的问题。
- 修复“后期合成”在通讯录、共享、协同和人力场景里展示口径不统一的问题。
- 修复共享、成员和排期相关契约测试没有覆盖新结构化字段的问题。
- 修复临时后端部署目录可能被误提交的问题，发布流程已排除 `backend-deploy-stage-*/`。

## 影响范围

前端主要影响通讯录、协同成员弹窗、成员权限弹窗、模板共享弹窗、项目头部成员摘要、排期部门筛选、人力资源视图、后台管理视图和相关样式。

后端主要影响工作区部门列表、联系人 / 成员映射、项目成员 payload、模板共享、排期服务、人力服务、管理后台服务和契约测试。旧字段仍保持兼容，现有前端可以继续读取 `members`、`memberRoles`、`sharedWith` 等 legacy 字段。
