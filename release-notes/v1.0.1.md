# MIX-OC v1.0.1 发布说明

发布日期：2026-05-19

`v1.0.1` 是一次面向前端协作体验、部门结构和排期兼容性的迭代。这个版本没有改变核心后端接口结构，重点是让任务、排期和协同成员选择更贴近真实部门层级。

## 更新摘要

- 新增任务创建部门树，任务会保存部门 key、部门名称和对应模块。
- 协同成员权限弹窗新增部门树筛选，支持美术设计、视效包装等二级部门。
- 排期创建仅展示新版部门入口，同时编辑旧排期时保留原模块，避免历史数据丢失。
- 排期工具栏部门筛选收敛为当前业务主线部门。
- 任务模块卡片增加部门色彩边框、拖拽反馈和选中状态。
- 前端测试链路新增排期创建弹窗部门兼容测试。

## 新增功能

### 任务部门树

新建任务时，用户不再需要从平铺的模块列表里猜部门。弹窗提供项目管理、美术设计一部、美术设计二部、三维动态设计部、视效包装一部、视效包装二部、视效包装三部等入口。任务保存时会把 `department`、`departmentKey` 和 `departmentLabel` 写入 payload，为后续人力分析、排期筛选和后端同步提供更准确的字段。

### 协同成员部门树

成员权限弹窗从简单部门按钮升级为树形导航。项目管理、美术设计、三维动态设计部、视效包装可以折叠展开，右侧列表会显示当前分组人数，并标记已经加入项目的成员，避免重复邀请。

### 排期兼容测试

新增 `frontend-source/src/components/schedule/__tests__/ScheduleCreateDialog.test.js`，把新版排期部门入口和旧模块编辑兼容纳入 `npm run test:schedule`。这可以防止后续迭代误删旧数据保护逻辑。

## 优化体验

任务模块使用统一的颜色变量，模块卡片在普通、选中、拖拽悬停和新近高亮状态下都有一致反馈。排期工具栏改为更短的主部门筛选，界面上不再同时展示 AIGC、动效、后期等旧分类。工作台顶部重复的新建任务入口被移除，减少流程页与排期页之间的误触。

## 修复问题

- 修复任务创建时部门字段没有进入任务 payload 的问题。
- 修复排期筛选不识别新版部门 key 的问题。
- 修复编辑旧排期时旧模块值无法展示在部门选项里的问题。
- 修复源码契约测试没有覆盖新版部门树结构的问题。
- 修复生产登录流程 smoke 对“密保问题未启用”中文提示的判断，避免已文档化的 404 兼容返回被误判为失败。
- 修复排期快照创建时误触发评论通知变量导致 500 的问题，排期快照/模板 smoke 可以覆盖这条链路。

## 影响范围

主要影响前端工作台、任务创建弹窗、协同成员权限弹窗、排期创建弹窗、排期工具栏和相关前端测试。后端包版本同步升到 `1.0.1`，接口结构保持兼容。
