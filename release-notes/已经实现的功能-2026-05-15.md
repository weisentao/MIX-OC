## 2. 技术栈

| 层 | 技术 | 当前用途 |
| --- | --- | --- |
| 前端框架 | Vue 3 | 单页应用、组件化界面 |
| 构建工具 | Vite 5 | 开发、构建、预览 |
| 状态管理 | Pinia | 全局工作台状态、权限、项目、任务、排期、画板 |
| 路由 | vue-router | 登录页和工作台页 hash 路由 |
| UI 库 | Element Plus | 弹窗、输入、消息、图标 |
| HTTP | axios | 统一请求 `/api` |
| 画板 | Excalidraw | 协作画板嵌入 |
| 动画 | animate.css | 页面、任务、反馈动效 |
| 视频 | video.js | 媒体播放器能力预留 |
| 后端 | Express | API 服务 |
| 数据库 | MySQL | 用户、项目、任务、排期、画板等正式表 |
| 缓存/队列 | Redis、BullMQ | 依赖已存在，素材/队列能力仍偏预留 |
| 鉴权 | JWT | 登录 token |

| 已登录访问工作台 | 放行 |
