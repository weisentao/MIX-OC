- `/workspace/*` 在 MySQL 不可用时会返回 503；在正式数据库上线版中这是环境阻塞，不再用 fallback 判定为可上线。
- `/appState/main` fallback 仍保留，只用于异常兜底和临时保底，不计入正式上线验收通过条件。
- 后端根路径 `/` 返回 404；健康检查应使用 `/health` 或 `/api/health`。
- 文件上传服务仍未接入正式对象存储或文件服务。
- 大包体构建 warning 仍存在，需后续拆包优化。
- Playwright 全入口自动化尚未沉淀为常规回归。
