# 已完成功能&已实现接口清单

> 文档用途：用于向新的开发者或 AI 交接当前已经完成的前端功能、后端接口、数据链路和验收口径。本文是独立文档，可单独阅读。

## 1. 总体完成度

当前项目已完成大量前端交互和部分正式后端数据库接口。整体口径如下：

| 类别 | 当前状态 |
| --- | --- |
| 前端页面与交互 | 大部分第一版/第五版/第七版可见功能已实现 |
| 登录注册 | 前后端均有实现，前端含 local fallback |
| 项目/任务/评论/标签 | 前端完整交互 + 后端模块化 API + MySQL 表 |
| 通讯录/部门/联系人 | 后端接口已实现，前端有通讯录入口 |
| 项目共享/成员 | 后端有共享和成员接口，前端有权限弹窗 |
| 协作画板 | 前端 Excalidraw 嵌入 + 后端数据库 CRUD/共享/历史 |
| 模板 | 前端功能较完整，后端仍是占位 |
| 后台管理 | 前端基础视图已实现，部分动作未接正式后端 |
| 文件上传 | 前端本地读取保存，正式文件服务未实现 |
| 正式上线 | 仍阻塞于 MySQL/JWT_SECRET/生产 smoke/浏览器验收 |

## 3. 后端已实现接口清单

说明：路由同时挂载在根路径和 `/api` 前缀下。前端生产一般访问 `/api/*`。下表以根路径展示，等价 `/api` 前缀也可用。

### 3.1 健康检查

| Method | Path | 鉴权 | 说明 |
| --- | --- | --- | --- |
| `GET` | `/health` | 否 | 服务健康检查 |

### 3.2 认证接口

| Method | Path | 鉴权 | 说明 |
| --- | --- | --- | --- |
| `POST` | `/login` | 否 | 账号密码登录，返回 token 和 user |
| `POST` | `/register` | 否 | 注册 `MIX-*` 账号 |
| `GET` | `/security-question?username=` | 否 | 密保问题兼容接口，当前提示未启用 |
| `POST` | `/forgot-password` | 否 | username + phone + newPassword 重置密码 |
| `POST` | `/change-password` | 是 | 登录用户修改密码 |
| `GET` | `/me` | 是 | 当前登录用户 |
| `GET` | `/dev/token` | 否 | 开发 token |

| MySQL 状态 | 行为 |

## 6. 已知完成但需谨慎验收的点

| 功能 | 注意事项 |
| --- | --- |
| 注册 | 后端和前端都有实现，但生产真实用户主要来自 seed |
| 忘记密码 | 后端以手机号校验，真实 seed 用户手机号多为空时不可用 |
| appState 保存 | 可用，但正式上线不能以 fallback 作为通过依据 |
| 后台用户管理 | 前端动作已存在，正式管理接口不完整 |
| 文件上传 | 前端可上传到本地状态，不是正式文件存储 |
| 模板共享 | 前端模拟，不是正式数据库共享 |
| 画板 | 已有保存/共享/历史，不是实时多人协同 |
