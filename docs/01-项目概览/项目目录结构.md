### 4.1 入口与路由

| `src/router/index.js` | Hash 路由、登录守卫、登录页和工作台页 |

### 4.2 服务层

| 文件 | 作用 |
| --- | --- |

| `src/services/workspaceApi.js` | 模块化工作台 API 封装，项目、任务、标签、画板等 |

## 12. 生成物与可忽略文件

可视为生成物或临时文件：

| 路径 | 说明 |
| --- | --- |
| `node_modules` | 依赖目录 |
| `dist` | 前端构建产物 |
| `run*.log` | 运行日志 |
| `src/logs/*.log` | 后端日志 |
| `deploy_tmp/*.tar.gz` | 部署归档 |
| `mock/db.json` | 可由 seed 生成的 mock 数据 |

注意：

- 生产部署时需要 `dist`，但开发交接时不要把 `dist` 当源码修改。
- 后端 `data/app-state-main.json` 是 fallback 数据，排错时有用，但不应作为正式数据库数据源。
- 当前根目录不是 Git 仓库，接手前应确认是否需要初始化或切换到实际版本管理目录。
