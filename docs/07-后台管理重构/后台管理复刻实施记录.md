## 后端接口预留

Admin 侧通过 `frontend-source/src/services/adminApi.js` 预留 `/admin/*`：

- dashboard / users / permissions / projects
- risk / schedules / boards / templates / tags
- notices / departments / archives / system
- create / update / archive / delete 类操作按页面实体分发

Manager 侧通过 `frontend-source/src/services/managerApi.js` 预留 `/manager/*`：

- overview / department / members / projects
- project detail / tasks / comments / schedule
- permissions / boards / templates / tags / archives / accounts
- 项目 manager 范围内的 create / update / archive / reset 等操作

后端接入注意：

- 前端当前仍会先做部分 optimistic update，后端联调时建议改成“接口成功后合并返回值”，失败时 rollback。
- 普通管理端必须由后端裁剪 scope，不能只靠前端 store 过滤。
- 普通管理只能授予 `manager/editor/readonly`，不能授予 `admin`。
- 危险操作建议统一要求 `reason`、`dryRun`、`confirmText`、`auditId`。
- 密码重置只能返回重置结果和审计 ID，不允许返回明文密码。

仍建议补齐的接口 hook：

- `adminApi.resetUserPassword`
- `managerApi.createComment/updateComment/deleteComment`
- `managerApi.createScheduleItem/updateScheduleItem/deleteScheduleItem`
- `managerApi.deleteProjectBoard/shareProjectBoard`
- `managerApi.updateProjectTemplate/deleteProjectTemplate/applyProjectTemplate`
- `managerApi.updateTag/deleteTag/restoreArchive`

## 权限边界

Admin Console：

- `admin` 超级管理员使用。
- 可看全站用户、项目、任务、评论、排期、画板、模板、标签、公告、归档、系统状态。

Manager Console：

- 普通管理、项目经理、项目管理、部门组长使用。
- 数据范围是本部门、负责分组、我的项目、当前项目。
- 项目 `manager` 权限等同管理该项目。
- 不开放全站 admin 能力、系统审计、全站归档、全站公告、全站用户管理。
