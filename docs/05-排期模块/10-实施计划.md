# 排期框架实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 PDF 中的项目排期时间线覆盖当前排期列表，并补齐排期计划、模板、快照、聊天、导出和后端落库能力。

**Architecture:** 前端以 `ScheduleView.vue` 为入口，拆分时间线、看板、节点、弹窗、快照和聊天组件；后端新增 schedule 路由、controller、service 和 MySQL 表；任务仍作为流程和排期联动的基础对象，但正式排期数据存入 schedule 专用表。

**Tech Stack:** Vue 3、Vite、Pinia、Element Plus、axios、Express、MySQL、JWT。
