## 4. 总体结论

当前系统已经有排期入口、排期任务字段、Kanban/List 两种视图、排期拖拽、项目时间字段、任务评论和后端任务接口。PDF 要求的新排期不是简单加一个页面，而是把排期升级成一个独立的“项目计划编排中心”。

推荐实现方式：

1. 保留 `任务 task` 作为流程任务和排期任务的基础数据。
2. 新增 `schedule_plans` 作为项目排期计划。
3. 新增 `schedule_items` 表达排期环节和任务条。
4. 新增 `schedule_snapshots` 保存快照历史。
5. 新增 `schedule_templates` 保存项目排期模板。
6. 前端用新 `ScheduleView.vue` 覆盖旧 Kanban/List 页面，并拆分成时间线、看板、节点三个视图组件。
7. 时间线视图作为默认主视图，完全复刻 PDF 的主画面。
8. 看板和节点视图共享同一套排期数据，不复制数据。
