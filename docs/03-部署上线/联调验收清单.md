# 联调验收清单

## 0. 前置环境

- 后端目录：`C:\Users\pveadmin\Desktop\mutou\第一版源代码\backend-source`
- 前端目录：`C:\Users\pveadmin\Desktop\mutou\第一版源代码\frontend-source`
- 固定端口：
  - MySQL：`3306`
  - 后端：`13001`
  - 前端：`15173`
- 默认代理：前端 `/api` -> `http://127.0.0.1:13001`

推荐先执行一键脚本：

```powershell
cd /d C:\Users\pveadmin\Desktop\mutou\第一版源代码\backend-source
powershell -ExecutionPolicy Bypass -File .\scripts\local-stack-acceptance.ps1 -Action start-and-check
```

## 1. 健康检查

1. 后端健康：`GET http://127.0.0.1:13001/health`
2. 后端 API 健康：`GET http://127.0.0.1:13001/api/health`
3. 前端代理健康：`GET http://127.0.0.1:15173/api/health`
4. 预期：
   - 三个接口均返回 `200`
   - 返回体包含 `ok=true`
   - 返回体包含 `ready=true`
   - 返回体包含 `checks.mysql.ready=true`

## 2. 登录

1. 使用真实验收口令登录
2. 预期：
   - 返回 token 与 user
   - 浏览器保存 `xjg_token` 与 `xjg_user`
   - 跳转工作台

说明：管理员密码以 `backend-source\.env` 中的 `ADMIN_INITIAL_PASSWORD` 为准，不在文档中展开明文。

## 3. 注册

1. 在登录页切到注册
2. 填写 `MIX-` 开头账号、密码、手机号、邮箱、姓名等
3. 预期：
   - 注册成功自动登录
   - 新账号可退出并重新登录

## 4. 退出

1. 在工作台点击退出登录
2. 预期：
   - 清除 `xjg_token`、`xjg_user`
   - 跳转 `/login`

## 5. 修改密码（已登录）

1. 登录后在工作台执行修改密码
2. 输入旧密码、新密码、确认新密码
3. 预期：
   - 请求命中 `POST /api/change-password`
   - 成功后提示成功并退出到登录页
   - 使用新密码可登录，旧密码不可登录

## 6. 忘记密码（未登录）

1. 登录页点击“忘记密码”
2. 输入账号
3. 若后端返回“未启用密保问题”，进入手机号找回步骤
4. 输入注册手机号 + 新密码
5. 预期：
   - 请求命中 `POST /api/forgot-password`
   - 重置后可用新密码登录

## 7. appState 加载保存

1. 登录后观察首次加载：`GET /api/appState/main`
2. 在页面进行任意状态变更
3. 预期：
   - 有 `PUT /api/appState/main` 请求
   - 刷新后状态可恢复

## 8. 业务联调重点

- 项目、任务、评论、标签、共享、通讯录、画板、后台管理均通过 `/api/*` 访问真实后端
- 刷新后数据仍从 MySQL 恢复
- 前端控制台无阻断错误

## 9. MySQL 不可用 fallback 行为

1. 仅用于异常演练，不作为上线通过依据
2. 验证：
   - `login/register/me/forgot-password/change-password` 可走 fallback
   - `appState` 可走文件 fallback
3. 结论：
   - fallback 只说明服务有兜底
   - 不等于正式上线通过

- 文档、脚本、口径统一使用 `13001`
- 一键脚本 `local-stack-acceptance.ps1` 可直接复用
