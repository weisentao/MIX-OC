# 后端技术架构&框架规范

> 文档用途：本文件用于交接后端工程 `G:\mutou\xm\xjg-api` 的服务架构、环境变量、启动流程、接口分层、数据库初始化、鉴权、错误处理、脚本和开发规范。本文档可单独交给后续后端开发或 AI 接手。

## 1. 工程定位

后端工程 `xjg-api` 是 MIX 项目任务清单与协作工作台的 Node.js API 服务。当前负责：

- 登录、注册、当前用户、忘记密码、修改密码。
- JWT 鉴权。
- MySQL 表结构初始化和真实用户 seed。
- 工作台模块化 API：项目组、项目、任务、评论、标签、通讯录、项目共享。
- 协作画板数据库 API：画板、画板共享、画板历史。
- `/appState/main` 兼容旧整体状态保存。
- Redis/BullMQ 预留。

工程路径：

```text

```

## 4. 环境变量规范

配置读取位置：`src/config/env.js`

关键项：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `NODE_ENV` | `development` | 运行环境。 |
| `PORT` | `3000` | 后端监听端口；联调/生产文档按 `3001` 使用，应在 `.env` 中显式配置。 |
| `API_PREFIX` | `/api` | API 前缀；服务同时挂载带前缀和不带前缀的路由。 |
| `LOG_LEVEL` | `info` | winston 日志级别。 |
| `REQUEST_BODY_LIMIT` | `80mb` | JSON/body 大小限制，当前用于头像/画板等大 JSON 兼容。 |
| `JWT_SECRET` | 空 | 必填。为空时启动失败。生产必须使用长随机值。 |
| `JWT_EXPIRES_IN` | `7d` | token 过期时间。 |
| `MYSQL_HOST` | `127.0.0.1` | MySQL 地址。 |
| `MYSQL_PORT` | `3306` | MySQL 端口。 |
| `MYSQL_USER` | `root` | MySQL 用户。生产建议改专用应用用户。 |
| `MYSQL_PASSWORD` | 空 | MySQL 密码。 |
| `MYSQL_DATABASE` | `xjg` | 数据库名称。 |
| `MYSQL_CONNECTION_LIMIT` | `10` | 连接池上限。 |
| `REDIS_HOST` | `127.0.0.1` | Redis 地址。 |
| `REDIS_PORT` | `6379` | Redis 端口。 |
| `REDIS_PASSWORD` | 空 | Redis 密码。 |
| `REDIS_DB` | `0` | Redis DB。 |

生产硬性要求：

- `JWT_SECRET` 不能为空，不能使用默认示例值。
- `MYSQL_DATABASE` 必须指向预期数据库 `xjg`。
- 生产建议使用专用 MySQL 用户，不使用 `root`。
- MySQL 必须通过生产检查和 smoke；`/appState/main` fallback 不能视为正式通过。

## 5. 启动流程

入口：`src/server.js`

```text
bootstrap()
  -> validateRequiredEnv()
  -> pingMySQL()
    -> 成功：ensureAuthTables()
      -> 创建 users、app_states
      -> ensureWorkspaceTables()
      -> seed admin 和真实用户
    -> 失败：服务继续启动，认证使用内存 fallback，workspace API 返回 503
  -> pingRedis()
    -> 失败只记录 warning，不阻断当前阶段启动
  -> app.listen(env.port)
```

启动设计说明：

- `JWT_SECRET` 缺失会直接阻止启动。
- MySQL 不可用不会阻止服务启动，但正式业务模块化 API 会返回 503。
- Redis 当前只是预留，不作为第一版阻塞。
- `ensureAuthTables()` 会自动调用 `ensureWorkspaceTables()`，因此 MySQL 可用时会创建完整业务表。

## 6. Express 应用结构

入口：`src/app.js`

中间件顺序：

```text
cors()
express.json({ limit: env.requestBodyLimit })
express.urlencoded({ extended: true, limit: env.requestBodyLimit })
requestLogger
app.use(env.apiPrefix, routes)
app.use(routes)
notFoundHandler
errorHandler
```

路由同时挂载：

- 带前缀：`/api/login`、`/api/workspace/bootstrap`
- 不带前缀：`/login`、`/workspace/bootstrap`

这样设计是为了同时兼容前端代理、Nginx `/api` 反代和直接本地调试。
